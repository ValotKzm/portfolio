# Product

## Platform

web

## Users

Primary users are recruiters evaluating Yannick Souza for an apprenticeship.

## Product Purpose

Present Yannick's projects and make it easy for recruiters to get in touch about an apprenticeship. The owner also wants the portfolio to support employment opportunities and professional networking.

## Positioning

A dual background: a master's degree in Natural Language Processing (Traitement Automatique des Langues) combined with ongoing full-stack developer training. This pairing is what sets the profile apart from other junior full-stack developers and makes it relevant for data and AI applications.

## Operating Context

Recruiters review the profile and projects, then contact Yannick. The current site provides project discovery and links to LinkedIn, GitHub, and email.

## Capabilities and Constraints

- The existing implementation uses Next.js 16, React 19, TypeScript, and Tailwind CSS 4.
- Project records are queried from PostgreSQL through Neon and Drizzle ORM.
- The current interface is in French.
- Confirmed profile: Yannick holds a master's degree in Natural Language Processing, is currently in full-stack developer training, specializes in backend and NLP, and is seeking an apprenticeship in full-stack, backend, or frontend development, with a particular interest in data and AI applications.
- Apprenticeship start date, duration, school/company schedule, location, and remote-work preferences are deliberately not recorded. Do not state or imply any of them.

## Evidence on Hand

- The repository contains a homepage with a profile introduction and project showcase, plus LinkedIn, GitHub, and email contact links.
- Project data is backed by a database schema, but no specific project records or outcomes were reviewed for this brief. Do not invent project details or results.
- The README mentions an interview-simulation project as a current focus; whether this remains current and is a shipped portfolio project is unconfirmed.

## Product Principles

- Help recruiters assess relevant project work.
- Make professional contact straightforward.
- Keep profile claims grounded in facts the owner has confirmed.
- Use a no-green, open-source-maintainer visual language to frame real work; never invent ratings, repository activity, code output, or security states.
